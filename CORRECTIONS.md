# Corrections log

A public record of every substantive error in published SourcingBench data
or copy: what was wrong, who caught it, and what changed. Scoring-model
revisions are tracked separately in [CHANGES.md](CHANGES.md); this file is
for errors of fact.

Report an error by opening a GitHub issue on this repository or emailing
the contact address on [SourcingTools.org](https://sourcingtools.org).
Demonstrated factual corrections are applied in the next cycle (or
immediately for non-score copy), credited here, and never silently.
